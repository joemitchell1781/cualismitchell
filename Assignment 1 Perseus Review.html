All About the Perseus Digital Library

Introduction

Context

The Perseus Digital Library is a project managed and run through Tufts University's Deparment of Classical Studies and consists of several linked collections of significant texts for scholars of ancient and Renaissance history, among other topics. The current version, 4.0, was released in 2005 and is hosted online at www.perseus.tufts.edu/hopper. This site is free to use and does not have any ads. It is supported by the donations of various organizations and individuals, who are credited on the website's homepage.
The Perseus Project launched its first iteration of this library in 1992, though the planning phase began in 1985. More information about this can be found on the Perseus website's version history page.

Users

The primary audience for this information system is students of the humanities. While this may usually be in an academic context, such as a college student taking classes on Greek or Latin, anyone with an internet connection can use this system. This means anyone interested in learning from these materials can use them! There is no user account system included in the Perseus website. All the main content for navigation is in English.

Content

The materials held in the Perseus Digital Library are a mix of primary texts, such as ancient Greek poems, or secondary/reference materials, such as dictionaries or other reference material. The list of their main collections is below.

List of Collections:

  • Greek and Roman Materials
  • Arabic Materials
  • Germanic Materials
  • 19th Century American
  • Renaissance Materials
  • Richmond Times Dispatch
  • Humanist and Renaissance Italian Poetry in Latin

The types of information that you tend to see in the reading mode for any given text are as follows:
  • Original language of the text
  • Text of an English translation if available (location/focus can be swapped between original and translation)
  • Table of contents for browsing/other navigational buttons
  • Search tool for searching the text for specific words
  • Citation of the work
  • Vocabulary tool in the sidebar

Discussion

Interesting Features

One of the most interesting features for this information system is the inbuilt vocabulary tool. Every word of a Greek or Latin text can be clicked on to be shown a page with the definition of that word in addition to the possible morphologies of the word itself. For example, clicking on a Latin verb will take you to a page that tells you the meaning of the word and what conjugation the word is following. This tool is really helpful for language learning as it will allow you to read what you do know and then quickly look up a word that you don't!

Pros and Cons of Perseus

The major pros for this system are that it is open source, has a large number of classical Greek and Latin texts, and that it has a built in vocabulary tool. The major cons are that the UI and search functionality are unintuitive and that the help pages themselves are somewhat old and outdated. There is also relatively minimal customization for the user's experience.

Suggested Improvements

In order to make Perseus an even better resource, the first thing that the website needs is a new UI that makes things less overwhelming and confusing to navigate. Keeping the vocabulary tool and all of the work that's gone into indexing the texts themselves is fine, but making it so that the information is easier to find would be great. I also think that there is room to improve on the customization front. There isn't a way to increase text size or make any changes other than selecting from a few pre-set character families for the Greek/Latin/Arabic alphabets. It could be useful to have a simple user system created so that a user could make an account and save all of their preferences through that account, potentially even allowing a user to bookmark or save certain works to a personal library (making navigation even easier!).
